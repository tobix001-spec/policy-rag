# Uploading Claim Documents on the Web Portal

## Overview

This article explains uploading claim documents on the web portal.

## Details

Accepted formats are PDF, JPG, PNG and HEIC.

Each file uploaded through the web portal can be up to 25 MB.

You can attach up to 20 files to a single claim from the web portal.

Uploads are virus-scanned before they reach an adjuster.
